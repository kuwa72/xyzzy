# コード調査のコンテキスト管理

コード調査では次の順番を守る。

1. `graphify-out/graph.json` があればGraphifyで関係を確認する
2. Serenaで対象ファイルのシンボル一覧を取得する
3. 関係する関数・クラスだけ本体を読む
4. 必要なら参照元・呼び出し元を追跡する
5. 1回に取得するコードは原則200行以内にする
6. 長い検索結果やログはHeadroomで圧縮する
7. 圧縮後に詳細が必要な場合だけ元データを再取得する
8. 関係が確認できるまで、関連ファイルを無制限に読まない
