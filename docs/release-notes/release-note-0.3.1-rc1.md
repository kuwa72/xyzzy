xyzzy リリースノート

  * ホームページ: <https://github.com/kuwa72/xyzzy>


この rc について
----------------

0.3.1 の rc である。**エディタの動作は 0.3.0 と変わらない。** 使うだけなら 0.3.0
のままでよい。

作り直したリリース経路を一度通しておくための版でもある。タグと `CMakeLists.txt` の
一致、リリースノートの存在、タグが `main` 上にあること、成果物が 3 アーキ分そろって
いることを検証したうえで公開されている。接尾辞付きのタグを prerelease として出す
経路も、これが最初の実行である (従来は `-preview` も正式リリース扱いで出ていた)。

中身は
[0.3.1 のリリースノート](https://github.com/kuwa72/xyzzy/blob/main/docs/release-notes/release-note-0.3.1.md)
を参照。要点は次の通り。

  * テストを結果で止めるようにした。既知の失敗を `misc/known-failures/` に名前で
    書き出し、それ以外で CI を止める。従来は `continue-on-error` で、赤くても
    マージもリリースもできた
  * リリースの検証。バージョン不一致、ノート欠落、`main` 外のタグ、アーキ欠落で
    止まる。`SHA256SUMS` を同梱する
  * 手順を `RELEASING.md` に書き、機械で判定できるものは git hook に降ろした


確認してほしいこと
------------------

rc なので、落として起動するところまで見てもらえると助かる。

  * インストーラと ZIP が 3 アーキ (x86 / amd64 / arm64) 分そろっているか
  * `SHA256SUMS` と実物が一致するか
  * このリリースが「latest」になっていないこと (prerelease の確認)
