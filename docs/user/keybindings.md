キーバインド
============

xyzzy は Emacs 風のキー操作です。多くのコマンドがモードごと・機能ごとに
別々のファイルでキーに割り当てられていて、単一の「デフォルトキーマップ」
という一覧表は xyzzy 自身の中にもありません。**実際に効いている全キー割り当ては
メニューの「ヘルプ」→「キー割り当て一覧」でいつでも確認できます** (現在の
バッファのモードで有効なものも含めて出ます)。ここでは最初に覚えると楽なものだけ
挙げます。

ファイル・終了
--------------

| キー | 動作 |
|---|---|
| `C-x C-f` | ファイルを開く |
| `C-x C-s` | 保存 |
| `C-x C-w` | 名前を付けて保存 |
| `C-x C-c` | xyzzy を終了 |
| `M-x` | コマンド名を指定して実行 |

M-x とミニバッファ
------------------

`M-x` や `C-x C-f` などでコマンド名・ファイル名を入力する下部の 1 行 (ミニバッ
ファ) にいるときの操作です (`lisp/minibuf.l`)。

| キー | 動作 |
|---|---|
| `RET` | 確定して実行 |
| `TAB` | 補完 |
| `SPC` | 単語単位で補完 (ファイル名補完などで) |
| `C-g` | 入力を中断してキャンセル |
| `ESC ESC` | 入力を中断してキャンセル |
| `C-p` / `↑` | 1 つ前の入力履歴を呼び出す |
| `C-n` / `↓` | 1 つ後の入力履歴を呼び出す |
| `M-p` | 1 つ前の入力履歴を呼び出す (`C-p` と同じ) |
| `M-n` | 1 つ後の入力履歴を呼び出す (`C-n` と同じ) |

ミニバッファの中では `C-p`/`C-n` が「1 行上/下へ移動」ではなく「履歴を辿る」に
上書きされている点に注意してください (1 行しかないので移動先が無いため)。文字
単位の移動 (`C-f`/`C-b`/`C-a`/`C-e` など) は通常のバッファと同じです。

基本の移動・編集
----------------

| キー | 動作 |
|---|---|
| `C-f` / `→` | 1 文字進む |
| `C-b` / `←` | 1 文字戻る |
| `C-n` / `↓` | 1 行下へ |
| `C-p` / `↑` | 1 行上へ |
| `C-a` / `Home` | 行頭へ |
| `C-e` / `End` | 行末へ |
| `C-v` / `PageDown` | 1 画面下へ |
| `M-v` / `PageUp` | 1 画面上へ |
| `C-d` / `Delete` | カーソル位置の 1 文字を削除 |
| `DEL` / `BS` | カーソルの前の 1 文字を削除 |
| `C-k` | カーソル位置から行末まで削除 (kill) |
| `C-y` | 直前に kill した内容を貼り付け (yank) |
| `C-SPC` / `C-@` | マークをセット (リージョンの起点) |
| `C-w` | リージョンを切り取り |
| `M-w` | リージョンをコピー |
| `C-t` | カーソル前後の 2 文字を入れ替え |
| `C-x C-x` | カーソル位置とマークを入れ替え |
| `Insert` | 上書きモードの切り替え |

バッファ・ウィンドウ
--------------------

| キー | 動作 |
|---|---|
| `C-x b` | バッファ切り替え |
| `C-x k` | バッファを閉じる |
| `C-x C-b` | バッファ一覧 |
| `C-x 2` | ウィンドウを上下に分割 |
| `C-x 1` | 他のウィンドウを閉じる |
| `C-x 0` | このウィンドウを閉じる |
| `C-x o` | 隣のウィンドウへ移動 |

移動
----

| キー | 動作 |
|---|---|
| `M-g` | 行番号を指定して移動 |
| `M-<` | バッファの先頭へ |
| `M->` | バッファの末尾へ |
| `M-@` | 単語を選択 |

検索・置換
----------

デフォルトの `C-s` / `C-r` はインクリメンタルではない (パターンを打って `RET` で
確定する) 検索です。打鍵ごとに絞り込む isearch は `lisp/isearch.l` にあります
が起動時のロード対象 (`lisp/loadup.l`) に入っておらず、デフォルトでは読み込まれ
ません。isearch にしたい場合は `~/.xyzzy` に以下を書いてください。

```lisp
(require "isearch")
```

`isearch.l` がロード時に `C-s` / `C-r` を isearch-forward / isearch-backward
に上書きします。

| キー | 動作 |
|---|---|
| `C-s` | 検索 (前方、パターンを入力して `RET`) |
| `C-r` | 検索 (後方) |
| `M-s` | 正規表現検索 (前方) |
| `M-C-s` | 正規表現検索 (後方) |
| `M-r` | 文字列を置換 |
| `C-M-r` | 問い合わせ置換 |

ファイラ
--------

ファイラを開いた状態で使えるキーです。

| キー | 動作 |
|---|---|
| `RET` | 開く |
| `D` | 削除 |

ターミナル
----------

`M-x shell` で開いたターミナルバッファ (詳細は [機能一覧](features.md#ターミナルエミュレータ))
の中で使えるキーです。

| キー | 動作 |
|---|---|
| `C-c C-c` | シェルに Ctrl-C を送る |
| `C-c C-f` | ファイルを開く |

Emacs との違いに注意
--------------------

xyzzy は Emacs 風ですが、指が Emacs に馴染んでいる人ほど事故りやすいキーが
いくつかあります。デフォルト状態 (どのファイルも `~/.xyzzy` で上書きしていない
状態) での違いです。

| キー | xyzzy での動作 | Emacs での動作 |
|---|---|---|
| `C-h` | 1 文字削除 (BS と同じ) | ヘルプ |
| `C-\` | undo | (割り当てなし) |
| `C-_` | redo | undo |
| `C-z` | 前ページへスクロール | フレームをサスペンド |
| `ESC SPC` | マークをセット | 空白を 1 個に詰める |
| `ESC /` | 空白を 1 個に詰める | dabbrev-expand |
| `C-x /` | dabbrev-expand | (割り当てなし) |
| `M-r` | 文字列を置換 | ウィンドウ内でカーソル行を移動 |
| `ESC ESC` | 式を評価 (eval-expression) | (割り当てなし。Emacs では `M-:`) |
| `C-x C-v` | 対応するファイルを開く (find-other-file) | 別のファイルを開き直す (find-alternate-file) |
| `C-x C-n` | バッファ名を変更 | ゴール桁を設定 |
| `C-x C-k` | 漢字コードを指定して入力 | キーボードマクロ編集 (Emacs 24 以降) |
| `C-x z` | ウィンドウを広げる | 直前のコマンドを繰り返す (Emacs 28 以降) |
| `C-x C-z` | ウィンドウを狭める | フレームをサスペンド |
| `C-x a` | 変数を設定 (set-variable) | abbrev 系コマンドのプレフィックス |
| `M-g` | 行番号を指定して移動 | goto-map のプレフィックス (`M-g g` で行移動) |

undo/redo (`C-\` / `C-_`) は Emacs と割り当てが逆なので特に注意してください。

キーバインドを変える
--------------------

GUI の設定ダイアログにキーバインドの編集機能はありません (一覧表示のみです)。
変更するには [Lisp で拡張する](lisp-extensions.md) の要領で `~/.xyzzy` に
`define-key` を書いてください。設定ファイルの構成全体については
[設定](configuration.md) を参照してください。
