実機での手作業確認 (CP932 経由の撤去)
=====================================

自動テストは Lisp から呼べる経路を見ている。ミニバッファの補完、ファイルを開く
ダイアログ、ファイラの表示、IME の再変換は目で見ないと分からないので、ここに
手順を書く。

準備
----

    C:\Users\ykuwa\Downloads\xyzzy-latest\xyzzy-amd64\xyzzy.exe

を起動する。同じ場所に修正前 (2be4424) の zip も置いてあるので、比べたければ
そちらを別のフォルダに展開する。

確認用のファイルを作る。PowerShell で:

    cd $env:USERPROFILE\Downloads
    mkdir cp932-check
    cd cp932-check
    "content" | Out-File -Encoding utf8 "日本語.txt"
    "content" | Out-File -Encoding utf8 "한국어시험.txt"
    "content" | Out-File -Encoding utf8 "简体字测试.txt"
    "content" | Out-File -Encoding utf8 "絵文字😀.txt"
    mkdir "디렉터리"
    "content" | Out-File -Encoding utf8 "디렉터리\abc.txt"

`한국어시험` と `简体字测试` は CP932 に無い文字を含む。`😀` は BMP の外。


見るもの
--------

### 1. ミニバッファの補完 (報告の「補完ができない」)

  * `C-x C-f` で `~/Downloads/cp932-check/` まで進み、`TAB` を押す。
    → 5 つの名前がそのまま出る。`?` や `??` が無い。
  * `한` まで打って `TAB`。→ `한국어시험.txt` に補完される。
  * `絵` まで打って `TAB`。→ `絵文字😀.txt` に補完される。
    以前はここで `絵文字??.txt` になっていた。
  * `디` まで打って `TAB`。→ ディレクトリ名が補完され、その下の `abc.txt` にも
    進める。

### 2. 開く (報告の「Open ができない」)

  * 上の 5 つをそれぞれ `C-x C-f` で開く。内容が `content` と読めて、
    「Invalid name」や「file not found」が出ない。
  * 開いたバッファでタイトルバーを見る。ファイル名がそのまま出て `?` にならない。
  * `C-x C-s` で保存し直せる。バックアップファイル (`~` 付き) も同じ名前で
    できる。

### 3. ファイルを開くダイアログ (報告の「ダイアログからも開けない」)

  * メニューの「ファイル」→「開く」でダイアログを出し、`cp932-check` を開く。
    → 一覧の名前が化けない。選んで開ける。

### 4. ファイラの表示

  * `M-x filer` で `cp932-check` を開く。
    → 名前の列が化けない。以前は CP932 に無い文字が `?` になっていた
    (listviewex.cc が wide → CP932 → wide の往復をしていた)。
  * ファイラから `Enter` で開ける。`c` (コピー) や `m` (移動) も名前が壊れない。

### 5. 文字として扱えること

`M-x eval-expression` で:

    (code-char 128512)          => #\😀 (char-code は 128512)
    (length "絵文字😀.txt")      => 8
    (char-code #\😀)            => 128512

バッファに `😀` を直接入力 (IME でも貼り付けでも) して、

  * カーソルが 1 回の `C-f` で越える (2 回ではない)
  * `M-x count-chars` 相当や `(point-max)` が文字数になっている
  * `C-s` で `😀` を検索して当たる

### 6. IME の再変換 (WM_IME_REQUEST)

日本語 IME を有効にして、確定済みの文字列を選択し、IME の再変換
(MS-IME なら `変換` キー、ATOK なら設定のキー) を押す。
→ 選択した文字列が候補として出る。以前は wide のバッファに CP932 の
バイトを詰めていたので、ここでゴミが出るか何も起きなかった。

### 7. 印刷のヘッダ

`M-x print-buffer` の設定で、ヘッダに `%F` (ディレクトリ付きファイル名) を
入れて `絵文字😀.txt` を印刷プレビューする。
→ ヘッダのファイル名が化けない。


それでも直っていない既知の点
----------------------------

  * 正規表現の文字クラス (`[...]`) は BMP 内だけを表にしているので、BMP 外の
    文字を範囲に入れた指定は効かない。リテラルとしての検索は効く。
  * 書庫 (lha/zip 等) の中のファイル名は DLL が ANSI 専用なので CP932 のまま。
  * ホスト名は ASCII でなければならない (punycode の変換は入れていない)。
