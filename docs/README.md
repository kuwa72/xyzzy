docs/ について
================

このディレクトリは3つに分かれています。

  * [user/](user/index.md) — 利用者向けドキュメント。インストール、機能一覧、
    キーバインド、設定、Lisp 拡張の書き方など。**リリースの ZIP / インストーラには
    ここだけが入ります。**
  * [dev/](dev/README.md) — 開発者向けドキュメント。ビルド方法、設計メモなど。
    配布物には入りません。
  * [release-notes/](release-notes/) — 各リリースの変更点となぜそうしたか。
    最新の (未リリース分の) 変更点は
    [release-notes/release-note-next.md](release-notes/release-note-next.md) に
    溜めています。配布物には入りません。GitHub の
    [Releases](https://github.com/kuwa72/xyzzy/releases) にも同じ内容が
    それぞれのタグに紐付いて載っています。

トップレベルの [README](../README.md) から辿ってきた場合は、まず
[user/index.md](user/index.md) を見てください。
