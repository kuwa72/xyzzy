xyzzy リリースノート
====================

  * バージョン: 0.2.6.8-pr3
  * リリース日: 2026-08-20
  * ホームページ: <https://github.com/kuwa72/xyzzy>


このリリースについて
--------------------

0.2.6.8-preview2 の入れ直しである。**preview2 のパッケージには tree-sitter の
文法が入っていなかった** ので、それを直した。他の変更は無い。

preview2 で書いたとおり、preview からのバイナリの動作の変更は無い。配布している
exe は MSVC でビルドしており、preview 以降の差分はビルド基盤と検証環境に入って
いる。詳細は 0.2.6.8-preview2 のリリースノートを参照。


修正
----

  * tree-sitter の文法をパッケージに入れた。

    ZIP もインストーラも、tree-sitter の Lisp 側だけが入っていて文法が入って
    いなかった。`lisp/ts.l` は `(si:system-root)/grammars/<lang>/` に共有
    ライブラリと `highlights.scm` が並んでいることを期待するので、無い状態では
    文法を使うモードのハイライトが働かない。

    c / cpp / perl / markdown (block と inline) の 5 つと、それぞれのクエリが
    入る。

    install 規則を足すだけでは足りなかった。文法ライブラリの出力先が
    `grammars/<lang>` すなわちソースツリーの中で、ビルド間で共有されていたため、
    アーキテクチャの違うライブラリが入りうる状態だった (実際、最初の試作では
    x86-64 のパッケージに ARM64 のライブラリが入った)。出力先をビルドツリーに
    移し、パッケージにはターゲットの出力を入れるようにした。開発中の実行は
    リポジトリルートの下を見るので、そこへはビルド後にコピーする。
