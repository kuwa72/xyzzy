xyzzy リリースノート
====================

  * バージョン: 0.2.6.8-preview
  * リリース日: 2026-08-19
  * ホームページ: <https://github.com/kuwa72/xyzzy>


このリリースについて
--------------------

kuwa72/xyzzy からのプレビュー版である。[snmsts/xyzzy](https://github.com/snmsts/xyzzy)
の `modern` を土台に、こちらで見つけたバグ修正を載せてある。

土台の側 (ARM64/x86-64 対応、Win32 API の Unicode 化、CMake 化、tree-sitter、
ncurses フロントエンドなど) は 0.2.6.3 のリリースノートを参照。ここには
0.2.6.3 以降にこの木で入れた分だけを書く。

プレビューと名の付くとおり、常用しての検証は済んでいない。


バグ修正
--------

  * 文字を 1 個 princ すると 0xFF を超える部分が落ちるのを直した。

    `(princ "平成")` は正しいのに `(princ (char "平成" 0))` が `"s"` になる、
    という壊れ方をしていた。内部表現を UTF-16/UCS-4 に移す途中で、文字列を
    丸ごと出す経路 (`print_string`) は `ucs4_t` に移ったが、文字 1 個を出す
    経路 (`print_char`) が `Char` (16bit) のままだったため。`StrBuf::add` の
    オーバーロードのうち、char リテラル用に `& 0xff` するものが整数拡張で
    選ばれ、上位バイトを捨てていた。

    表に出ていたのは `format-date-string` の `%#g` (元号の 1 文字目) と
    `%v` (日本語の曜日) で、どちらも直っている。x86 / x86-64 / ARM64 の
    3 アーキで確認した。

  * `last` をドットリストに使えるようにした (upstream #426)。

    `last` はリストではなく末尾のコンスを返す関数なのでドットリストにも使えるが、
    0.2.2.239 で循環検出のために `Flist_length` を通すようにしたときから
    `(last '(1 2 . 3))` がエラーになっていた。

  * 幅を超える右シフトで `ash` が誤った値を返すのを直した (upstream #422)。

    シフト量が long の幅以上のとき x86 はシフト量をマスクするので
    `(ash 64 -64)` が 64 を返していた。32bit と 64bit で結果が変わる箇所でもある。
    bignum 側も、右シフトでリムを全部落とすときに未クリアの領域を読んでいて、
    以前の長い値の残りが結果に出ることがあった。

  * ファイラでジャンクションを削除すると参照先の中身が消えるのを直した
    (upstream #421)。

    ジャンクションは `FILE_ATTRIBUTE_DIRECTORY` を持つため `file-directory-p`
    が `t` を返し、`directory` がリンクをたどって参照先のファイルを再帰的に
    削除していた。リンクだけが消えて参照先のディレクトリは残るので気付きにくい。
    reparse point を見て中に入らないようにした。

  * 祝日表を現行法まで追補した。

    2019/4/30 の国民の休日と、2020・2021 のオリンピックによる海の日・
    スポーツの日・山の日の移動が入っていなかった。海の日と山の日の上限も付けた。

  * x86 で tree-sitter がリンクできず、2026-05-07 以降 CI が赤のままだったのを
    直した。`ts_tree_edit` を stdcall/cdecl ブリッジに足し忘れていた。


テスト
------

  * 祝日と元号のテストが無かったので `unittest/calendar-tests.l` を追加した。
    `last`、`ash`、および今回の princ の回帰テストも足してある。

  * CI でテストを実行するようにした。除外はファイル単位ではなくテスト単位にし、
    除外するのは実行そのものを壊すもの (クラッシュ・ハング) に限っている。
    落ちるだけのテストは落としたまま見えるようにしてある。


既知の問題
----------

CI で落ち続けているテストが 10 件ある (`xyzzy-ini-path`、`octet-length-utf8`、
`octet-length-eucjp`、`hmac-sha2-test-case-3`、OLE 関連、`float-00` など)。
いずれも今回の変更より前からのもので、未着手である。
